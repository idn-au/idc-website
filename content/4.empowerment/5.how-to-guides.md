## IDN Catalogue Profile Guide

The Guidance Document is where you want to start. It is a dedicated document explaining the why and how of the main [Specification Document](https://data.idnau.org/pid/cp/spec).

In the context of a metadata catalogue such as the Indigenous Data Network Catalogue, the 'catalogue profile' is the rules, elements and specifications that inform how metadata is structured and recorded in the catalogue. It includes such elements as the vocabularies, the fields and the relationships that are created to ensure data is described in a consistent manner which ultimately supports better data governance. This guide is to help you record and find data in the Indigenous Data Catalogue and to help you better understand the underlying structure of the catalogue.

::LinkButton{to="https://data.idnau.org/pid/cp/guide"}
Go to the Guidance Document
::
